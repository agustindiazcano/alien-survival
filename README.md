# Alien Survival

Alien Survival is an experimental web game prototype developed using **Babylon.js** (WebGL).

## Description

The game is an **action wave-based survival** where the player must survive constant attacks from alien enemies. As you progress, the waves become harder, requiring quick reflexes and good resource management.

### Main Mechanics

*   **Survival Waves:** Survive multiple waves of enemies. The difficulty (enemy health, damage, and spawn rate) increases with each wave.
*   **Progression System (RPG Lite):** Defeated enemies drop gold and experience orbs (XP). Leveling up restores the player's health.
*   **Shop and Upgrades:** Between waves or during gameplay, the player can access a shop to spend collected gold on:
    *   Upgrading the basic rifle's damage and fire rate.
    *   Buying health medkits and armor.
    *   Acquiring new weapons (Flamethrower, Plasma, Laser).
    *   Buying and upgrading **allied drones** that can heal the player or attack nearby enemies with missiles.
*   **Varied Arsenal:** Different weapons with unique firing mechanics and damage (from rapid bursts to area of effect damage or continuous laser beams).
*   **Cross-platform Support:** Controls adapted for playing on both **Desktop** (with keyboard and mouse) and **Mobile Devices**.

## Technologies Used

*   HTML5 / CSS3 / JavaScript
*   [Babylon.js](https://www.babylonjs.com/) for 3D rendering and physics.
*   Babylon GUI for the user interface (HUD, health bars, radar, shop).
